# Toxoplasma-bradyzoite-reactivation-analysis
This repository contains analysis scripts used in "Single-cell atlas reveals reactivation of chronic toxoplasmosis proceeds through a sequential developmental cascade".

## Contents
### R scripts
`Fig_3B_3C_3D_3E.R` - scRNAseq clustering, visualization, and heatmap analyses.
`Fig_4A_4G_4H_4I.R` - Cell cycle annotation and pseudotime analyses.
`Fig_5B_S3A_correlation.R` - Spearman correlation analysis.
`Fig_S2C_S2D_splines.R` - Gene expression spline analysis along pseudotime.

### RNA velocity analysis
`Fig_4B_velocyto.sh` - Velocyto preprocessing used for the RNA velocity analysis.
`Fig_4B_scvelo.py` - scVelo analysis.

### CellProfiler pipelines
`Fig_1I_S1B_S1E_fluorescence_intensity.cpproj` - Fluorescence intensity measurements.
`Fig_S5C_S6C_vacuole_size.cpproj` - Vacuole size measurements.
`Fig_S5E_S6E_fluorescence_intensity.cpproj` - Fluorescence intensity measurements.

## Data availability
Raw sequencing data are available through NCBI BioProject PRJNA1346446.
